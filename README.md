# 📊 Dashboard Landing Page

A simple and clean dashboard-style landing page built with HTML and CSS. This project focuses on layout structuring, responsive design, and modern UI styling without using any frameworks.

---

## 🚀 Features

* 📐 Structured dashboard layout
* 🎨 Clean and modern UI design
* 📱 Responsive design for different screen sizes
* 🧩 Organized sections (sidebar, header, main content)
* ⚡ Lightweight and fast (no JavaScript required)

---

## 🧱 Tech Stack

* **HTML** – page structure
* **CSS** – layout and styling (Flexbox / Grid)
